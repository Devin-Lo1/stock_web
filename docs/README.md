# Docs

项目文档入口。

推荐阅读顺序：

1. `APP开发强约束规范.md`  
   当前项目最高优先级约束，包含编码、架构边界、网络调试、富途、策略、回测、推送和验证要求。

2. `APP架构审计与优化路线.md`  
   当前代码和 docs 扫描结论，记录后续项目框架结构优化路线。

3. `APP项目结构说明.md`  
   当前代码目录和主要文件职责说明。

4. `APP马上解决任务顺序.md`  
   当前版本之后的短期执行清单。若与审计路线冲突，以 `APP架构审计与优化路线.md` 顶部当前状态为准。

5. `APP后续开发方案.md`  
   长期功能路线和历史开发记录。

6. `APP总体开发规划.md`  
   总体定位、阶段路线和环境说明。

后续新增架构约束、模块边界或优化路线时，应优先更新 `APP架构审计与优化路线.md` 和 `APP开发强约束规范.md`。
