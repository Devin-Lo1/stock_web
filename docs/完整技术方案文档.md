## 1. 项目概述

### 1.1 项目背景

用户在工银智投进行港股交易，需要一个智能助手来：
- 记录和管理持仓数据
- 实时获取市场行情（通过富途API）
- 生成买卖信号
- 实时查看盈亏和交易数据

### 1.2 核心需求

#### 功能需求
1. **持仓管理**: 手动录入工银智投的持仓信息
2. **实时行情**: 对接富途API获取实时股价
3. **信号生成**: 基于技术指标生成买卖信号
4. **盈亏计算**: 实时计算每只股票和总体盈亏
5. **数据展示**: 图表、列表等多维度展示
6. **推送通知**: 重要信号推送到手机

#### 非功能需求
1. **性能**: 行情延迟 < 1秒
2. **可用性**: 99%在线率
3. **安全性**: 数据加密，用户认证
4. **可扩展性**: 支持未来添加更多策略

### 1.3 用户场景

```
场景1: 添加持仓
用户在工银智投买入中国平安100股，成本价50 HKD
→ 在APP中手动添加持仓记录
→ 系统开始实时跟踪该股票

场景2: 接收买卖信号
系统检测到中国平安MA5上穿MA20（金叉）
→ 生成买入信号
→ 推送通知到用户手机
→ 用户在工银智投APP执行买入

场景3: 查看盈亏
用户打开APP
→ 看到总资产、今日盈亏
→ 点击中国平安查看详情
→ 看到实时价格、盈亏百分比、K线图
```

- ✅ 高性能内存数据库
- ✅ 支持多种数据结构
- ✅ 适合缓存实时行情

#### 4.2.2 实时行情服务

**功能描述**:
对接富途API，获取实时股价，推送到APP端。

**技术实现**:
```python
# 使用WebSocket推送实时行情
from futu import *

class MarketService:
    def __init__(self):
        self.quote_ctx = OpenQuoteContext(host='127.0.0.1', port=11111)
    
    def subscribe_realtime(self, stock_codes):
        """订阅实时行情"""
        self.quote_ctx.subscribe(stock_codes, [SubType.QUOTE])
        self.quote_ctx.set_handler(QuoteHandler())
    
    def get_realtime_price(self, stock_code):
        """获取实时价格"""
        ret, data = self.quote_ctx.get_market_snapshot([stock_code])
        if ret == RET_OK:
            return data['last_price'][0]
        return None
```

**数据推送流程**:
```
富途API推送行情
  ↓
后端接收并缓存到Redis
  ↓
通过WebSocket推送到APP
  ↓
APP更新UI显示
```

#### 4.2.3 策略引擎

**功能描述**:
基于技术指标生成买卖信号。

**支持的策略**:
1. **双均线策略**: MA5/MA20金叉死叉
2. **MACD策略**: MACD金叉死叉
3. **RSI策略**: 超买超卖
4. **布林带策略**: 突破上下轨
5. **自定义策略**: 用户可配置参数

**信号生成流程**:
```
定时任务（每分钟）
  ↓
获取最新K线数据
  ↓
计算技术指标
  ↓
判断买卖条件
  ↓
生成信号并保存
  ↓
推送通知到用户
```

**代码示例**:
```python
class StrategyEngine:
    def generate_signals(self, stock_code):
        """生成交易信号"""
        # 获取历史数据
        df = self.get_kline_data(stock_code, days=60)
        
        # 计算技术指标
        df = self.calculate_indicators(df)
        
        # 判断信号
        signal = self.check_signal(df)
        
        if signal:
            self.save_signal(stock_code, signal)
            self.send_notification(stock_code, signal)
        
        return signal
    
    def check_signal(self, df):
        """检查买卖信号"""
        latest = df.iloc[-1]
        previous = df.iloc[-2]
        
        # 金叉买入
        if previous['MA5'] <= previous['MA20'] and \
           latest['MA5'] > latest['MA20']:
            return {
                'type': 'BUY',
                'reason': 'MA5上穿MA20（金叉）',
                'price': latest['Close']
            }
        
        # 死叉卖出
        if previous['MA5'] >= previous['MA20'] and \
           latest['MA5'] < latest['MA20']:
            return {
                'type': 'SELL',
                'reason': 'MA5下穿MA20（死叉）',
                'price': latest['Close']
            }
        
        return None
```

#### 4.2.4 盈亏计算

**实时盈亏计算**:
```python
def calculate_profit(position, current_price):
    """计算盈亏"""
    cost = position.quantity * position.cost_price
    market_value = position.quantity * current_price
    profit = market_value - cost
    profit_rate = (profit / cost) * 100
    
    return {
        'profit': profit,
        'profit_rate': profit_rate,
        'market_value': market_value
    }
```

**总资产计算**:
```python
def calculate_total_assets(user_id):
    """计算总资产"""
    positions = get_user_positions(user_id)
    total_market_value = 0
    total_cost = 0
    
    for pos in positions:
        current_price = get_realtime_price(pos.stock_code)
        total_market_value += pos.quantity * current_price
        total_cost += pos.quantity * pos.cost_price
    
    total_profit = total_market_value - total_cost
    total_profit_rate = (total_profit / total_cost) * 100
    
    return {
        'total_assets': total_market_value,
        'total_cost': total_cost,
        'total_profit': total_profit,
        'total_profit_rate': total_profit_rate
    }
```

### 7.4 核心功能实现

#### 7.4.1 获取实时报价

```python
from futu import *

class FutuMarketService:
    def __init__(self):
        self.quote_ctx = OpenQuoteContext(host='127.0.0.1', port=11111)
    
    def get_realtime_quote(self, stock_codes):
        """
        获取实时报价
        
        Args:
            stock_codes: 股票代码列表，如 ['HK.02318', 'HK.00700']
        
        Returns:
            DataFrame: 实时报价数据
        """
        ret, data = self.quote_ctx.get_market_snapshot(stock_codes)
        
        if ret == RET_OK:
            return data
        else:
            print(f'获取报价失败: {data}')
            return None
    
    def subscribe_quote(self, stock_codes):
        """订阅实时报价"""
        ret, data = self.quote_ctx.subscribe(
            stock_codes,
            [SubType.QUOTE],  # 订阅实时报价
            subscribe_push=True
        )
        
        if ret == RET_OK:
            print(f'订阅成功: {stock_codes}')
        else:
            print(f'订阅失败: {data}')
    
    def get_quote_callback(self):
        """设置报价回调"""
        class QuoteHandler(StockQuoteHandlerBase):
            def on_recv_rsp(self, rsp_pb):
                ret_code, data = super().on_recv_rsp(rsp_pb)
                if ret_code == RET_OK:
                    # 处理实时报价数据
                    print(data)
                return ret_code, data
        
        self.quote_ctx.set_handler(QuoteHandler())
    
    def close(self):
        """关闭连接"""
        self.quote_ctx.close()

# 使用示例
service = FutuMarketService()

# 获取实时报价
quotes = service.get_realtime_quote(['HK.02318', 'HK.00700'])
print(quotes)

# 订阅实时推送
service.subscribe_quote(['HK.02318'])
service.get_quote_callback()

# 保持程序运行以接收推送
import time
time.sleep(60)

service.close()
```

```python
def get_kline_data(self, stock_code, start_date, end_date, ktype=KLType.K_DAY):
    """
    获取K线数据
    
    Args:
        stock_code: 股票代码，如 'HK.02318'
        start_date: 开始日期，如 '2026-01-01'
        end_date: 结束日期，如 '2026-04-29'
        ktype: K线类型
            - KLType.K_1M: 1分钟
            - KLType.K_5M: 5分钟
            - KLType.K_15M: 15分钟
            - KLType.K_30M: 30分钟
            - KLType.K_60M: 60分钟
            - KLType.K_DAY: 日K
            - KLType.K_WEEK: 周K
            - KLType.K_MON: 月K
    
    Returns:
        DataFrame: K线数据
    """
    ret, data, page_req_key = self.quote_ctx.request_history_kline(
        stock_code,
        start=start_date,
        end=end_date,
        ktype=ktype,
        autype=AuType.QFQ,  # 前复权
        fields=[KL_FIELD.ALL],
        max_count=1000
    )
    
    if ret == RET_OK:
        return data
    else:
        print(f'获取K线失败: {data}')
        return None
```

```python
import asyncio
from fastapi import WebSocket

class RealtimeQuoteService:
    def __init__(self):
        self.quote_ctx = OpenQuoteContext(host='127.0.0.1', port=11111)
        self.subscribed_stocks = set()
    
    async def stream_quotes(self, websocket: WebSocket, stock_codes: list):
        """
        通过WebSocket推送实时行情
        
        Args:
            websocket: WebSocket连接
            stock_codes: 股票代码列表
        """
        # 订阅股票
        for code in stock_codes:
            if code not in self.subscribed_stocks:
                self.quote_ctx.subscribe([code], [SubType.QUOTE])
                self.subscribed_stocks.add(code)
        
        # 设置回调处理器
        class QuoteHandler(StockQuoteHandlerBase):
            def __init__(self, ws):
                super().__init__()
                self.ws = ws
            
            def on_recv_rsp(self, rsp_pb):
                ret_code, data = super().on_recv_rsp(rsp_pb)
                if ret_code == RET_OK:
                    # 将数据推送到WebSocket
                    asyncio.create_task(
                        self.ws.send_json(data.to_dict('records'))
                    )
                return ret_code, data
        
        self.quote_ctx.set_handler(QuoteHandler(websocket))
        
        # 保持连接
        try:
            while True:
                await asyncio.sleep(1)
        except Exception as e:
            print(f'WebSocket错误: {e}')
        finally:
            self.quote_ctx.close()
```

### 7.5 错误处理和重连机制

```python
import time
from functools import wraps

def retry_on_failure(max_retries=3, delay=5):
    """重试装饰器"""
    def decorator(func):
        @wraps(func)
        def wrapper(*args, **kwargs):
            for attempt in range(max_retries):
                try:
                    return func(*args, **kwargs)
                except Exception as e:
                    if attempt < max_retries - 1:
                        print(f'第{attempt + 1}次尝试失败: {e}，{delay}秒后重试...')
                        time.sleep(delay)
                    else:
                        print(f'达到最大重试次数，操作失败')
                        raise
        return wrapper
    return decorator

class RobustFutuService:
    def __init__(self):
        self.quote_ctx = None
        self.connect()
    
    @retry_on_failure(max_retries=3, delay=5)
    def connect(self):
        """建立连接"""
        if self.quote_ctx:
            self.quote_ctx.close()
        
        self.quote_ctx = OpenQuoteContext(host='127.0.0.1', port=11111)
        print('富途API连接成功')
    
    @retry_on_failure(max_retries=3, delay=2)
    def get_quote(self, stock_codes):
        """获取报价（带重试）"""
        ret, data = self.quote_ctx.get_market_snapshot(stock_codes)
        
        if ret == RET_OK:
            return data
        else:
            raise Exception(f'获取报价失败: {data}')
```

### 7.6 数据缓存策略

```python
import redis
import json
from datetime import timedelta

class CachedFutuService:
    def __init__(self):
        self.futu_service = FutuMarketService()
        self.redis_client = redis.Redis(host='localhost', port=6379, db=0)
    
    def get_quote_with_cache(self, stock_codes, cache_ttl=5):
        """
        获取报价（带缓存）
        
        Args:
            stock_codes: 股票代码列表
            cache_ttl: 缓存时间（秒）
        
        Returns:
            dict: 报价数据
        """
        result = {}
        uncached_codes = []
        
        # 先从缓存获取
        for code in stock_codes:
            cache_key = f'quote:{code}'
            cached_data = self.redis_client.get(cache_key)
            
            if cached_data:
                result[code] = json.loads(cached_data)
            else:
                uncached_codes.append(code)
        
        # 获取未缓存的数据
        if uncached_codes:
            fresh_data = self.futu_service.get_realtime_quote(uncached_codes)
            
            if fresh_data is not None:
                for _, row in fresh_data.iterrows():
                    code = row['code']
                    quote_data = row.to_dict()
                    
                    # 存入缓存
                    cache_key = f'quote:{code}'
                    self.redis_client.setex(
                        cache_key,
                        cache_ttl,
                        json.dumps(quote_data)
                    )
                    
                    result[code] = quote_data
        
        return result
```

```dart
import 'package:web_socket_channel/web_socket_channel.dart';
import 'dart:convert';

class WebSocketService {
  WebSocketChannel? _channel;
  Function(Map<String, dynamic>)? onQuoteUpdate;
  Function(Map<String, dynamic>)? onSignalUpdate;
  
  void connect(String token) {
    _channel = WebSocketChannel.connect(
      Uri.parse('wss://api.yourdomain.com/ws?token=$token'),
    );
    
    _channel!.stream.listen(
      (message) {
        final data = json.decode(message);
        
        switch (data['type']) {
          case 'quote':
            onQuoteUpdate?.call(data['data']);
            break;
          case 'signal':
            onSignalUpdate?.call(data['data']);
            break;
        }
      },
      onError: (error) {
        print('WebSocket错误: $error');
        // 重连逻辑
        Future.delayed(const Duration(seconds: 5), () {
          connect(token);
        });
      },
    );
  }
  
  void subscribe(List<String> stockCodes) {
    _channel?.sink.add(json.encode({
      'action': 'subscribe',
      'stock_codes': stockCodes,
    }));
  }
  
  void close() {
    _channel?.sink.close();
  }
}
```

```dart
import 'package:flutter/foundation.dart';
import '../models/position.dart';
import '../services/api_service.dart';

class PositionProvider with ChangeNotifier {
  List<Position> _positions = [];
  bool _isLoading = false;
  
  List<Position> get positions => _positions;
  bool get isLoading => _isLoading;
  
  double get totalMarketValue {
    return _positions.fold(0, (sum, p) => sum + p.marketValue);
  }
  
  double get totalProfit {
    return _positions.fold(0, (sum, p) => sum + p.profit);
  }
  
  double get totalProfitRate {
    final totalCost = _positions.fold(0.0, (sum, p) => sum + (p.costPrice * p.quantity));
    return totalCost > 0 ? (totalProfit / totalCost) * 100 : 0;
  }
  
  Future<void> fetchPositions() async {
    _isLoading = true;
    notifyListeners();
    
    try {
      final data = await ApiService().getPositions();
      _positions = data.map((json) => Position.fromJson(json)).toList();
    } catch (e) {
      print('获取持仓失败: $e');
    } finally {
      _isLoading = false;
      notifyListeners();
    }
  }
  
  Future<void> addPosition(Position position) async {
    try {
      await ApiService().addPosition(position.toJson());
      await fetchPositions();
    } catch (e) {
      print('添加持仓失败: $e');
      rethrow;
    }
  }
  
  void updateQuote(String stockCode, double currentPrice) {
    final index = _positions.indexWhere((p) => p.stockCode == stockCode);
    if (index != -1) {
      _positions[index].currentPrice = currentPrice;
      notifyListeners();
    }
  }
}
```

```python
import logging
from logging.handlers import RotatingFileHandler
import os

def setup_logging():
    # 创建日志目录
    log_dir = "logs"
    os.makedirs(log_dir, exist_ok=True)
    
    # 配置日志格式
    formatter = logging.Formatter(
        '%(asctime)s - %(name)s - %(levelname)s - %(message)s'
    )
    
    # 应用日志
    app_handler = RotatingFileHandler(
        f'{log_dir}/app.log',
        maxBytes=10*1024*1024,  # 10MB
        backupCount=10
    )
    app_handler.setFormatter(formatter)
    
    # 错误日志
    error_handler = RotatingFileHandler(
        f'{log_dir}/error.log',
        maxBytes=10*1024*1024,
        backupCount=10
    )
    error_handler.setLevel(logging.ERROR)
    error_handler.setFormatter(formatter)
    
    # 配置根日志记录器
    root_logger = logging.getLogger()
    root_logger.setLevel(logging.INFO)
    root_logger.addHandler(app_handler)
    root_logger.addHandler(error_handler)
    
    # 控制台输出
    console_handler = logging.StreamHandler()
    console_handler.setFormatter(formatter)
    root_logger.addHandler(console_handler)
```

## 12. 风险评估

### 12.1 技术风险

#### 12.1.1 富途API稳定性

**风险描述**:
- 富途API可能出现故障或限流
- FutuOpenD需要本地运行，可能崩溃

**应对措施**:
```
1. 实现重连机制
2. 添加备用数据源（如Yahoo Finance）
3. 监控FutuOpenD运行状态
4. 设置自动重启脚本
```

**代码示例**:
```python
class FutuAPIWithRetry:
    def __init__(self, max_retries=3):
        self.max_retries = max_retries
        self.quote_ctx = None
    
    def connect(self):
        for i in range(self.max_retries):
            try:
                self.quote_ctx = OpenQuoteContext(
                    host='127.0.0.1',
                    port=11111
                )
                return True
            except Exception as e:
                print(f'连接失败，重试 {i+1}/{self.max_retries}')
                time.sleep(5)
        return False
```

```
1. 多数据源交叉验证
```

#### 12.1.3 系统性能

**风险描述**:
- 高并发时系统响应慢
- 数据库查询效率低

**应对措施**:
```
1. 使用Redis缓存热点数据

3. 异步处理耗时任务
4. 负载均衡
```
