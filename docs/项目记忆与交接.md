## 1. 项目目标

本项目是一个智能量化交易助手，第一阶段优先做安卓 App MVP。

核心闭环目标：

```text
手动录入持仓
  -> 展示持仓列表
  -> 计算当日收益和持有收益
  -> 根据阈值生成本地策略信号
  -> 后续接入后端和富途 API 自动刷新行情/K线
```

当前还没有正式接入数据库、富途 API、Firebase 推送。现阶段主要在完善 Flutter 静态交互和页面结构。

### 3.7 收益计算

`StockPosition` 现在是结构化模型，核心字段：

```dart
name
code
quantity
costPrice
currentPrice
previousClose
changeRate
signal
```

计算逻辑：

```text
成本金额 = quantity * costPrice
市值 = quantity * currentPrice
持有收益 = 市值 - 成本金额
持有收益率 = 持有收益 / 成本金额
当日收益 = (currentPrice - previousClose) * quantity
当日收益率 = (currentPrice - previousClose) / previousClose
```

颜色规则：

```text
红色 = 盈利/上涨
绿色 = 亏损/下跌
灰色 = 辅助文本
```

这是按港股/国内用户习惯。

### 3.8 策略信号

信号现在不是死数据，而是由当前筛选市场下的持仓动态生成。

默认阈值：

```text
止盈观察：+5%
止损观察：-5%
上涨异动：+5%
下跌异动：-5%
```

生成规则：

```text
持有收益 >= 止盈阈值      -> TAKE_PROFIT
持有收益 <= 止损阈值      -> STOP_LOSS
当日涨幅 >= 上涨异动阈值  -> DAILY_SURGE
当日跌幅 <= 下跌异动阈值  -> DAILY_DROP
```

信号页和首页“最新信号”都会跟随持仓、市场筛选、策略阈值变化。

## 5. 富途 API 相关结论

后续应该把现价、昨收、涨跌幅、K 线等行情数据交给后端自动更新。

```text

```

可用接口方向：

```text

request_history_kline(...)

```

后续建议流程：

```text

  -> FastAPI 后端
  -> futu-api / FutuOpenD
  -> 获取现价、昨收、K线
  -> 后端返回结构化 JSON
  -> Flutter 刷新持仓、收益、图表、信号
```
